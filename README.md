# TinySteps

Baby milestones by month: enter your baby's birth date for a personalized 0-24 month milestone timeline with check-off tracking. Free tool.

## Features
- Personalized milestone timeline from birth date with check-off progress saved on device
- Next-milestone countdown with preemie corrected-age adjustment
- Printable milestone checklist export for pediatrician visits
